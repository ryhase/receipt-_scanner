📖 初期セットアップ・GitHub Pages 公開手順
  1. Google スプレッドシートと Apps Script の準備: スプレッドシートの [拡張機能] → [Apps Script] に Code.gs と appsscript.json を配置します。
  2. スクリプト プロパティの設定: Apps Script の [プロジェクトの設定] (⚙️) → [スクリプト プロパティ] に GEMINI_API_KEY を追加します。
  3. ウェブアプリとしてデプロイ: Apps Script の [デプロイ] → [新しいデプロイ] で種類「ウェブアプリ」を選択し、アクセスできるユーザーを「全員」にしてデプロイします。発行された URL をコピーします。
  4. GitHub Pages の公開: GitHub リポジトリの [Settings] → [Pages] で Build and deployment を「Deploy from a branch (main / root)」に設定して公開します。
  5. 本画面で URL を保存: 公開された GitHub Pages 上で、上の「GAS Web App URL」欄にコピーした URL を貼り付けて保存します。
